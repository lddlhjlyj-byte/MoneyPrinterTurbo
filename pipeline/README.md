# 쇼츠 제작 파이프라인 (역할 분리)

영상 1개는 아래 5단계를 순서대로 거친다. 각 단계의 결과물은 `content/briefs/<name>.md`에 모아 기록한다.
`<name>`은 영상마다 고유한 영문 이름이다(같은 이름을 재사용하면 파일이 덮어써진다).

| 단계 | 역할 | 하는 일 | 결과물 |
|---|---|---|---|
| 1 | 기획자 | 주제·시청자·후킹 후보 3개 중 1개 선택 | brief.md의 "기획" |
| 2 | 작가 | 장면별 내레이션·화면 글자 작성 | brief.md의 "대본" |
| 3 | 디자이너 | 장면별 그림·움직임·표정 지정 | brief.md의 "스토리보드" |
| 4 | 제작자 | cards.json 작성 → 푸시 → 자동 렌더링 → 예약 게시 | cards.json, 영상, 썸네일, 예약 |
| 5 | 검수자 | 제작에 관여하지 않은 별도 에이전트가 점검 | brief.md의 "검수" |

규칙
- 검수자는 대본·스토리보드·cards.json만 보고 비판한다. 제작자의 설명은 주지 않는다.
- 검수에서 "수정 필요"가 나오면 해당 단계로 돌아간다. 수정 후 재검수는 심각한 항목만 한다.
- 확인하지 못한 것은 brief.md에 "미확인"으로 적는다.
- 세부 규칙은 `pipeline/roles/`의 역할별 문서를 따른다.
