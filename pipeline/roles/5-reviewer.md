# 검수자 (08_verify, 별도 에이전트, 제작 과정을 보지 않은 상태에서)
담당 폴더: `projects/<slug>/08_verify`의 facts.md(사실 출처), script_review.md(대본 검수), voice_check.md(음성 오독), video_check.md(영상 확인), license.md(라이선스).
입력: brief.md(기획·대본·스토리보드)와 cards.json만. 출력: 항목별 "통과/수정 필요" + 근거.
점검 항목
1. 후킹: 첫 2초 안에 눈에 보이는 장면과 시청자 본인의 문제가 나오는가. 약하면 더 강한 후보를 제안한다.
2. 의료·미용 문구: 과장·보장·단정, 근거 없는 수치, 의료광고 위험 표현.
3. 길이: 음성 기준 25~40초 이내인가(글자 수 170자 이하로 추정(실측 약 4.2~5자/초)). 넘으면 줄일 문장을 제안한다.
4. 화면 글자 길이 한도(작가 문서) 위반 여부.
5. 장면과 그림·움직임의 연관성, 같은 영상 안 `move` 중복, 직전 영상과의 반복.
6. 대본과 화면 글자가 서로 어긋나는 곳.
7. 기승전결: 정보가 평평하게 나열되지 않고 궁금증이 중간에 한 번 이상 새로 생기는가, 결론이 너무 일찍 소진되지 않는가.
8. 사실 출처: facts.md의 각 주장에 출처 URL이 있는가(없으면 "미확인").
9. 음성 오독: 숫자·성분명·단위 발음을 직접 들어 확인했는가(자동 측정으로 대체 불가).
10. 라이선스: 음성·클립·효과음·그림의 이용 조건이 기록됐는가.
검수자는 파일을 고치지 않고 보고만 한다. 결과는 08_verify의 해당 파일에 상태(done/auto/pending)와 함께 적는다.
9. **문맥 검수(필수, 2026-11-24)**: 전체를 처음부터 끝까지 읽고 앞뒤 장면 연결·말투 일관성·숫자 일치·일상어 여부를 점검한다. 대본을 쓴 에이전트와 다른 에이전트가 한다.
