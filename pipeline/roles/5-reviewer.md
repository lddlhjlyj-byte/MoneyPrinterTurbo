# 검수자 (별도 에이전트, 제작 과정을 보지 않은 상태에서)
입력: brief.md(기획·대본·스토리보드)와 cards.json만. 출력: 항목별 "통과/수정 필요" + 근거.
점검 항목
1. 후킹: 첫 2초 안에 눈에 보이는 장면과 시청자 본인의 문제가 나오는가. 약하면 더 강한 후보를 제안한다.
2. 의료·미용 문구: 과장·보장·단정, 근거 없는 수치, 의료광고 위험 표현.
3. 길이: 음성 기준 50~60초 이내인가(글자 수로 추정).
4. 화면 글자 길이 한도(작가 문서) 위반 여부.
5. 장면과 그림·움직임의 연관성, 같은 영상 안 `move` 중복, 직전 영상과의 반복.
6. 대본과 화면 글자가 서로 어긋나는 곳.
검수자는 파일을 고치지 않고 보고만 한다.
