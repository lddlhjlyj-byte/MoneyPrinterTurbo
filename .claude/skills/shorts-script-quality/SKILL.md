# 쇼츠 대본 품질 기준 (2026-11-22, 실측 반영)

## 길이 (실측)
- 제작된 21편 측정: 음성 글자 수 ÷ 영상 길이 = 중앙값 4.9자/초(3.9~5.5). 장면 사이 쉼 포함.
- 35~40초 = 공백 제외 약 175~200자. 150자는 약 30초. 330자는 약 65초(기존 한도가 틀렸던 이유).
- 사용자가 준 대본은 길어도 문구를 바꾸지 않고 길이만 알린다.

## 작성 순서 (결론부터)
1. 훅 후보를 10개 이상 쓰고, 서로 다른 유형(손해·오해·숫자·질문·반전·경고)에서 고른다. 공식 개수를 제한하지 않는다. 고른 이유를 한 줄 적는다.
2. 훅은 0~3초, 첫 호흡 24자 이하, 시청자가 뜨끔할 문장 + 구체적 숫자 또는 손해.
3. 기승전결: 기(뜨끔 훅) → 승(오해의 이유 1개) → 전(반전: 대부분 모르는 한 가지) → 결(오늘 밤 바로 할 행동 1개). 중간에 호기심을 다시 켜는 문장("근데 진짜 문제는 이 다음이에요")을 1번 넣는다.
4. 2~3초마다 새 정보·숫자. 문장 15~22자, 말투는 ~요/~죠.
5. 시각 명사·동사로 쓴다. 예) "피부가 좋아집니다" → "푸석했던 볼에 투명한 수분 광이 돕니다".
6. 한 줄 15~20자로 줄바꿈(스톡 매칭 경로에서 필수, InfoCard는 비트 자막이 자동 분할).

## 스토리 (정보 나열 금지, 2026-11-22 사용자 지시)
- 정보만 나열한 영상은 경쟁력이 없다. 모든 대본은 마스코트 노랑이의 사건으로 시작한다(실수→증상→원인·바른 방법→다음 편 예고).
- 노랑이의 경험은 허구 연출이다. 실제 후기·진료 경험처럼 쓰지 않고, 사실 주장은 출처 있는 항목만 쓴다.
- 마지막 줄은 다음 편 예고로 끝내 연속 시청·구독 이유를 만든다. 효과는 우리 영상으로 아직 검증 전(미확인).

## 의학·효능 문구
- 성분 농도·시술 효과·주기 같은 숫자는 출처 URL을 `01_research`에 적고, 못 찾으면 "미확인"으로 표시한다. 단정("무조건", "100%") 금지.
- 프로젝트 자료(`hadm_skin_booster_manual.txt`, `skin_care_manual.txt`)의 숫자도 외부 출처로 대조하기 전에는 "미확인".

## 출력 형식 (프로젝트 지침)
1. 플랫폼별 제목: 쇼츠용 / 릴스용 구분
2. 오디오 대본(줄바꿈 적용)
3. 화면 연출 가이드(명사 중심 검색어)
4. 통합 해시태그 7개

## 검수 질문
- 훅이 3초 안에 손해/호기심을 주는가? 중간에 이탈 지점(유지율 25% 지점)이 비어 있지 않은가?
- 마지막 줄이 행동 하나로 끝나는가? 길이가 200자 이하인가?
- 출처 없는 숫자가 남아 있지 않은가?

## 문맥점검 (매 세션·매 작성 시 필수, 결과는 NOTES.md에 기록)
- 일상에서 실제로 쓰는 말인가? "D-7", "취업 사진 찍기"처럼 글에서만 쓰는 표현은 "일주일 전", "증명사진"처럼 말하는 표현으로 바꾼다.
- 처음 보는 사람이 첫 3초에 이해하는가? 약어·전문용어는 풀어 쓴다.
- 앞뒤 장면의 인물·수치·이야기가 맞는가? 출처 없는 의학 문구는 없는가?
- 점검하지 않은 항목은 "미점검"으로 적는다.
