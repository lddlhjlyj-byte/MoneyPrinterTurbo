# salmon-repair-cream-guide — 연어재생크림, 제대로 바르는 법 4가지
유튜브 제목: 연어재생크림, 제대로 바르는 법 4가지 / 예약: 날짜 미정(사용자 답변 대기)
대본 출처: 사용자가 지피티에서 받아 붙여넣은 cards.json(2026-11-12). Claude가 교정 후 연출을 지정함

## 1. 기획
- 시청자: 재생크림을 쓰는데 밀리거나 답답함을 느끼는 사람
- 한 줄 약속: 바르는 순서·양·확인법 4가지
- 후킹: "크림 바르는데 왜 밀릴까요?" (지피티 원안 유지, 직접 질문 + 본인 경험). 대안 후보는 검수 칸 참고
- 의료·화장품 주장 근거: 사용 요령 일반론만 사용. 효능 문구 없음. 출처 확인 안 함(미확인)

## 2. 지피티 원안에서 교정한 것
- title 장면: text "사용법 4가지"와 num "4가지"가 겹쳐 "사용법 4가지 4가지"로 표시됨 → text를 "연어재생크림"으로 변경
- 글자 한도 초과: item2 tag "과도한 도포 금지"(8자), item3 tags "스킨케어 마무리"(8자)·"제품 설명 확인"(7자), summary rows "세안 후 물기 제거"(10자) → 줄임
- 아이콘 불일치: item1(세안 후 물기)=병 → 수도꼭지, item4(피부 반응)=가습기 → 패치 테스트 아이콘(새로 제작), item2·item3가 둘 다 보습제 → item3는 병
- summary 음성이 화면 4줄 순서와 달라 순서에 맞게 수정

## 3. 스토리보드
| 장면 | 내용 | 그림 | move | gesture | 표정 |
|---|---|---|---|---|---|
| hook | 크림 밀림 질문 | - | 기본(점프·자막 끌어내림) | up | 놀람 |
| title | 연어재생크림 4가지 | 큰 숫자 | 기본(쾅) | pointR | 기본 |
| item1 | 물기 닦기 | 수도꼭지 | nod | pointR | 기본 |
| item2 | 소량 얇게 | 보습제 | run | both | 기본 |
| item3 | 마지막 단계 | 병 | tilt | pointL | 기본 |
| item4 | 피부 반응 확인 | 패치 테스트 | tremble | shy | 놀람·땀방울(n=4 기본 worry) |
| summary | 핵심 정리 | 번호 4줄 | 기본(4번 점프) | count | 기본 |
| outro | 많이 바르기보다 제대로 | - | 기본(점프·회전) | wave | 기본 |
※ 직전 영상(winter-dry-skin)과 겹치지 않게 item 동작을 nod/run/tilt/tremble로 변경. 표정 변형은 미구현.

## 4. 검수
검수자(별도 에이전트, 2026-11-12) 결과와 조치
- 글자 한도 위반 없음, 길이 통과(음성 274자, 씬 합계 54초; 실제 음성 길이는 렌더링 후 probe로 확인)
- 동작 중복 없음(직전 영상과의 반복은 검수자가 확인 불가)
- summary 화면 "피부 반응 확인"과 음성 "피부 반응 살피기" 차이 → 음성을 "확인"으로 맞춤
- 후킹 수정 필요(밀림 장면 그림이 없음) → **미반영**(hook은 그림 칸이 없음. 대안: "밀리는 크림,/원인은 이것!", "바르자마자/밀리나요? 순서!")
- 표시·광고 위험: 제품명·해시태그의 '재생'(#연어재생크림 #재생크림), #피부장벽은 효능 암시 소지(검수자 판단, 심의 기준은 확인 불가) → **미반영**, 사용자 확인 필요(실제 상품명인지)
