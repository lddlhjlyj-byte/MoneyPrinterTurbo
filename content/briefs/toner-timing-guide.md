# toner-timing-guide (기획·작가·디자이너 기록)

## 기획
- 사유: 2026-11-13 분석(노랑이 3개 영상 vs 한국 스킨케어 쇼츠 상위 약 29개) 반영. 상위는 13~45초·답을 숨긴 제목·첫 3초 후킹, 노랑이는 53~67초·제목에 답 나열.
- 시청자: 세안 후 토너를 바르는데 효과를 모르겠거나 얼굴이 당기는 20~40대.
- 약속: 토너는 "언제·어떻게·무엇으로 마무리"만 바꿔도 달라진다 (3가지).
- 후킹 후보: ① "세안 후 토너, 몇 분 뒤에 바르죠?" ② "토너, 화장솜으로 닦아내고 계신가요?" ③ "토너 3가지만 바꿔 보세요" → ① 선택(시청자 본인의 행동 + 숫자 + 정답을 바로 주지 않는 질문. ②는 근거가 약해 폐기)
- 제목: 답을 숨기는 질문형 "토너, 바르는 타이밍 놓치고 계신가요?"

## 대본 (음성 250자, 목표 25~40초)
- 후킹 → 제목(3가지) → 항목 3개 → 요약 → 마무리 (why·signs 생략해 길이 단축)
- 숫자: 3분 안, 하루 2번(보통 아침·저녁)

## 근거 (확인 수준)
- 확인함: 세안 후 피부가 젖어 있을 때 토너를 바름 / 손으로 두드리거나 화장솜 사용 / 아침·저녁 사용 / 토너 뒤 보습제 / 알코올·향료 많은 제품은 건조할 수 있음 (CeraVe 안내 페이지, Dr. Portela 인용)
- 확인함: 이마·코·턱(T존)부터, 눈가·입술은 제외 / 화장솜으로 붉어지면 손으로 누르기 (Dermstore 블로그, Dr. Zalka 인용)
- 간접 근거: "3분 안" 수치는 Cleveland Clinic·GQ Korea의 '세안·샤워 후 3분 이내 보습' 기준을 토너 단계에 적용한 것. 토너 자체의 3분 기준을 직접 밝힌 출처는 못 찾음 → 게시 전 확인 필요
- 미확인: 토너 사용량(mL·번 두드리는 횟수), 화장솜 vs 손의 제품 낭비 차이(Adore Beauty 글 본문 못 읽음). 영상에 쓰지 않음
- 영상에 쓰지 않은 확인 내용: 알코올·향료·강한 수렴제 주의(자리 부족)

| hook | 세안 후 토너 몇 분 뒤? | 기본 | 기본 점프(자막 끌어내림) | 기본 | 놀람(구현됨) |

- 직전 영상(winter-numbers-routine: shiver/tilt/hop3/sway/spinJump/rise)과 겹치는 순서 없음. tilt는 쓰였지만 장면 위치가 다름. 같은 영상 안 move 중복 없음.
- 표정 변형은 미구현(놀람·땀방울·입 모양만). 장면별 표정은 지정하지 못함.

## 검수
- 규칙 검사(rules.py): 통과
- 별도 에이전트 검수(제작 과정 비공개 상태): 후킹·글자 한도 통과 / 수정 필요 4건 → 모두 반영
  1. 토너 3분 직접 출처 없음 → 후킹·item1 음성을 "3분 안이 좋다고 해요/알려져 있어요"로 완화
  2. 후킹 음성 과속(31자/4초) → "세안 후 토너까지 몇 분 걸리세요? 3분 안이 좋다고 해요."
  3. summary·outro 동작이 기본값 → summary sway, outro hop3 지정
  4. "톡톡" 불일치 → "가볍게", item3 sub "토너는 보통 아침·저녁"으로 주체 명확화
- 남은 위험: "3분 안" 근거는 간접(보습 기준 적용). 게시 전 확인 필요
