# 대본 검수
- 별도 검수 에이전트(처음 보는 검수자)가 전체 읽고 지적 10건, 아래 수정 반영:
  - hook '히터 방향부터 바꾸세요'(원인 단정) → '히터 바람부터 돌려 보세요'
  - 장면2 mood angry → normal (권유 대사와 불일치)
  - '정기적으로' → '꾸준히' (저장소 금지어 '기적' 검사)
  - 마무리 '내일은' → '다음 편은' (업로드 날짜 보장 불가)
  - hook에 '사무실'을 넣어 소리만 들어도 상황이 보이게 함
- 재검수는 하지 않음. 장면 사진·음성 확인은 렌더링 후 진행(확인 전).
