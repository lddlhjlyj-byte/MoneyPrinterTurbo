# 기획 — 4편 결말(전날 밤·면접 당일)
- 노랑이 1인 내레이션(2인 대화 미구현), 시연 씨는 3인칭 이야기 속 인물
- 시간선: 7일 전(1편) → 엿새(1편 끝·2편) → 닷새(2편 끝·3편) → 전날 밤(3편 끝·4편) → 당일(4편)
- 각 편 ≈190~200자, 끝에 다음 편 질문, 4편은 댓글 유도
- 아이콘은 허용 6종뿐이라 내용과 안 맞을 수 있음(알려진 한계)

- 2026-11-23 사용자 지시: '가상 사례' 글자 삭제(화면 표기 없음). 장면 표정(mood)은 그 장면 대사의 감정에 맞춤, 아이콘 7종 추가(mirror·pimple·calendar·hand·stop·clinic·document)
